# 一、计算科学 / 固态电解质（3 篇）

## 1. 非晶氧卤化物是实现锂超离子输运的关键

### 1. 基本信息

- **英文标题**：Amorphous Oxyhalide Matters for Achieving Lithium Superionic Conduction
- **作者**：Shumin Zhang、Feipeng Zhao、Lo-Yueh Chang、Yu-Chun Chuang、Zhen Zhang、Yuanmin Zhu、Xiaoge Hao、Jiamin Fu、Jiatang Chen、Jing Luo、Minsi Li、Yingjie Gao
- **主要机构**：中国科学技术大学、同步辐射研究中心（台湾）等
- **发布日期 / 类型 / 期刊**：2024-01-29；同行评审研究论文；Journal of the American Chemical Society 146(5), 3127–3136 (2024)
- **DOI / 原文**：[10.1021/jacs.3c07343](https://doi.org/10.1021/jacs.3c07343)
- **代码 / 数据**：论文未给出独立代码仓库；结构表征数据（XAS、PDF）随论文补充信息提供。

### 2. 入选理由与期刊质量

卤化物固态电解质是当前高电压全固态电池的核心候选材料，但以往研究几乎完全聚焦于晶态相。本文首次系统证明非晶组分在机械化学合成卤化物中普遍存在且直接决定快离子输运，提出了"非晶氧卤化物结构工程"这一新方向。JACS 是化学领域顶级综合期刊，重视兼具机理性发现与实验验证的工作；本文通过同步辐射 X 射线吸收谱、对分布函数分析与逆向蒙特卡洛建模形成完整证据链，符合该期刊定位。

### 3. 一句话亮点

揭示卤化物固态电解质中非晶组分的 Zr–O/Cl 面共享多面体结构是实现锂超离子输运的真正活性来源，而非此前认为的晶态相。

### 4. 核心工作

作者针对机械化学法合成的 Zr 基卤化物固态电解质（如 Li₂ZrCl₆），发现其并非纯晶态而是含有大量非晶组分。通过调控氧掺杂量，实现了非晶化程度的系统控制。研究证明正是非晶相中的 Zr–O/Cl 面共享多面体结构提供了低势垒锂离子迁移通道，使材料获得高离子电导率。

### 5. 最重要的部分

最关键的是建立了"非晶结构–局域化学环境–离子输运"的因果闭环：氧掺杂诱发的非晶 Zr–O/Cl 多面体结构经 X 射线吸收谱、对分布函数与逆向蒙特卡洛建模联合确证，计算（AIMD）又证明该结构降低锂离子迁移势垒，最终电化学测试给出高电导率。若缺少其中任一环节，"非晶组分决定输运"仅是推测。

### 6. 它是怎么做的

- **材料体系**：Li–Zr–Cl–O 卤化物体系，通过球磨法调控氧含量。
- **结构表征**：同步辐射 X 射线吸收近边结构（XANES）与扩展边（EXAFS）分析 Zr 局域配位；对分布函数（PDF）分析短/中程序；逆向蒙特卡洛（RMC）建模重构非晶三维结构。
- **计算验证**：基于 RMC 重构结构进行 AIMD 模拟，计算锂离子迁移势垒与扩散路径。
- **电化学测量**：阻抗谱测量室温离子电导率与活化能。
- **基线**：纯晶态 Li₂ZrCl₆ 及其他无氧卤化物对照。
- **评价指标**：室温离子电导率、迁移活化能、非晶相体积分数、Zr–O 配位数。具体仪器参数与 AIMD 超胞规模未披露。

### 7. 与别人不同在哪里

以往卤化物固态电解质研究（包括已在本日报中出现的"Designing lithium halide solid electrolytes"和"Tuning collective anion motion"）均以晶态结构工程为核心策略，将非晶相视为需要消除的缺陷。本文反其道而行，证明非晶组分是快离子输运的活性来源，且可通过氧掺杂定量调控——这不只是"优化已有材料"，而是开辟了"非晶氧卤化物"这一新成分–结构空间。

### 8. 关键结果与证据

- 氧掺杂后 Zr 基卤化物的**室温离子电导率从约 10⁻⁵ S cm⁻¹ 量级提升至 ~0.81 mS cm⁻¹**（数量级跃升）。
- XANES/EXAFS 证明 Zr–O 配位随氧含量增加而系统性变化，PDF 出现非晶特征宽峰。
- AIMD 计算显示非晶 Zr–O/Cl 面共享结构中锂离子迁移势垒显著低于晶态路径。
- 电导率达到了卤化物固态电解质实用门槛（~1 mS cm⁻¹），但仍低于顶级硫化物（~10 mS cm⁻¹）。

### 9. 局限与可迁移价值

局限包括非晶结构的精确表征仍有不确定性（RMC 建模依赖假设）、非晶相在长循环中的稳定性未充分验证、氧掺杂对电化学窗口的影响需进一步研究。可迁移价值很高：非晶结构工程思路可推广至其他卤化物体系（Na、K 离子导体），氧卤化物结构描述符可纳入固态电解质高通量筛选与机器学习预测流程。

### 10. 我的判断

**跟进优先级：高。** 这是改变卤化物固态电解质设计范式的工作，实验与计算证据链完整，直接指向可合成的新材料空间。

## 2. 高通量确定过渡金属氧化物的 Hubbard U 与 Hund J 值

### 1. 基本信息

- **英文标题**：High-throughput determination of Hubbard U and Hund J values for transition metal oxides via the linear response formalism
- **作者**：Guy C. Moore、Matthew K. Horton、Edward Linscott、Alexander M. Ganose、Martin Siron、David D. O'Regan、Kristin A. Persson
- **主要机构**：劳伦斯伯克利国家实验室、加州大学伯克利分校、帝国理工学院、都柏林三一学院
- **发布日期 / 类型 / 期刊**：2024-01-29；同行评审研究论文；Physical Review Materials 8, 014409 (2024)
- **DOI / 原文**：[10.1103/PhysRevMaterials.8.014409](https://doi.org/10.1103/PhysRevMaterials.8.014409)
- **预印本**：[arXiv:2201.04213](https://arxiv.org/abs/2201.04213)
- **代码 / 数据**：计算流程基于 Materials Project 的 atomate 框架；Hubbard U 值数据库已整合入 Materials Project 数据平台，可通过 API 查询。

### 2. 入选理由与期刊质量

DFT+U 是计算 correlated 材料最常用的校正方法，但 U 值的选取长期缺乏系统标准，研究者多靠经验试错或引用零散文献值。本文首次以高通量方式对 2000+ 种过渡金属氧化物自动计算 U 与 J 值，提供了可检索的大规模参考数据库。Physical Review Materials 是 APS 旗下专注计算与材料物理的权威期刊，适合这类方法+数据驱动的系统性工作。

### 3. 一句话亮点

开发自动化工作流对 2000 余种过渡金属氧化物计算 DFT+U(+J) 的 Hubbard U 与 Hund J 参数，揭示了 U 值随元素、氧化态与配位环境的变化规律。

### 4. 核心工作

作者基于线性响应（linear response, LR）方法，在 atomate 高通量框架中实现了自动化工作流，对 2000+ 种磁性过渡金属氧化物的 d 电子态计算 U 和 J 值。结果提供了按元素、氧化态、配位多面体分类的 U/J 值统计分布，为 DFT+U 计算提供了系统参考基准。还展示了该工作流在自旋倾斜（spin-canting）计算中的应用。

### 5. 最重要的部分

最关键的不是单个 U 值，而是"自动化工作流 + 大规模数据库"的组合：线性响应方法虽然已有理论基础，但此前从未在如此大规模（2000+ 材料）上系统执行。atomate 工作流使其可在超算上自动运行，而 Materials Project 数据库使结果可被社区直接检索使用——这把 DFT+U 参数从"每篇文章手动确定"变成了"可查标准参考"。

### 6. 它是怎么做的

- **材料集合**：2000+ 种磁性过渡金属氧化物（3d、4d 过渡金属），数据来自 Materials Project 数据库。
- **方法**：基于 Hitchen–Cococcioni 线性响应方法，在非自洽和自洽密度微扰下计算 d 轨道的 U 和 J 值。
- **工作流**：atomate 框架管理 VASP 计算，自动化处理结构优化、投影态密度、线性响应拟合与 U/J 提取。
- **评价**：将计算的 U 值与文献中实验/高精度计算值对比验证；分析 U 值随元素种类、氧化态、配位环境的统计分布。
- **应用示范**：用计算的 U 值进行自旋倾斜角计算，验证参数对磁性行为预测的影响。
- **未披露**：具体计算精度指标的详细统计表（如平均绝对误差）。

### 7. 与别人不同在哪里

已有 DFT+U 参数研究通常针对单一材料体系手动计算，缺乏可迁移性与统计意义。本文首次以高通量方式覆盖整个过渡金属氧化物化学空间，使得 U 值不再是孤立数字，而是可按化学环境检索的数据库条目。与基于实验拟合或经验估计的方法相比，线性响应方法具有第一性原理基础且可自动化执行。

### 8. 关键结果与证据

- 计算了 **2000+ 种过渡金属氧化物**的 U 与 J 值，覆盖 3d/4d 过渡金属的多种氧化态与配位环境。
- U 值统计显示其**随氧化态升高而增大**、随配位数变化等明确化学趋势。
- 数据库已整合入 Materials Project，可通过 API 按化学式或元素检索。
- 自旋倾斜应用示范证明使用计算 U 值可改善磁性预测。

### 9. 局限与可迁移价值

局限包括：U 值依赖线性响应方法的假设（线性化响应、局域 d 态近似）；仅覆盖氧化物体系，硫化物/氮化物等需扩展；U 值在强电荷转移体系中的适用性需谨慎。可迁移价值很高：该工作流和数据库可直接服务于固态电解质界面计算（如含过渡金属的氧化物正极/电解质界面）、催化剂表面计算和电池材料缺陷计算，提供标准 DFT+U 参数参考。

### 10. 我的判断

**跟进优先级：高。** 提供了 DFT+U 社区急需的大规模参考数据库与自动化工作流，对所有涉及过渡金属氧化物的计算研究都有直接实用价值。

## 3. EPW 代码：第一性原理电子–声子物理

### 1. 基本信息

- **英文标题**：Electron–phonon physics from first principles using the EPW code
- **作者**：Hyungjun Lee、Samuel Poncé、Kyle Bushick、Samad Hajinazar、Jon Lafuente-Bartolome、Joshua Leveillee、Chao Lian、Jae-Mo Lihm、Francesco Macheda、Hitoshi Mori、Hari Paudyal、Weng Hong Sio、Sabyasachi Tiwari、Marios Zacharias、Xiao Zhang
- **主要机构**：洛桑联邦理工学院（EPFL）、加州大学圣地亚哥分校、牛津大学等
- **发布日期 / 类型 / 期刊**：2023-08-25；同行评审研究论文（软件+方法）；npj Computational Materials 9, 140 (2023)
- **DOI / 原文**：[10.1038/s41524-023-01107-3](https://doi.org/10.1038/s41524-023-01107-3)
- **代码 / 数据**：EPW 是开源代码，集成于 [Quantum ESPRESSO](https://www.quantum-espresso.org/) 套件中，代码仓库位于 [QuantumESPRESSO/q-e](https://github.com/QuantumESPRESSO/q-e)（含 EPW 模块）；文档与教程见 [epw-code.org](https://epw-code.org)。

### 2. 入选理由与期刊质量

电子–声子耦合是决定材料载流子迁移率、超导转变温度、光学带隙温度依赖和极化子行为的物理核心，但第一性原理计算长期缺乏统一高效的开源平台。EPW 自 2016 年后新增了输运、超导、光学、极化子和能带重整化五大模块，成为该领域事实标准工具。npj Computational Materials 是 Nature 旗下专注计算材料学的期刊，适合这种兼具方法论深度与广泛社区影响力的工作。

### 3. 一句话亮点

将密度泛函微扰理论与最大局域化 Wannier 函数结合，在单一开源框架内实现载流子输运、声子介导超导、光学间接跃迁、极化子计算与能带温度重整化五大类电子–声子物理性质的第一性原理预测。

### 4. 核心工作

EPW（Electron–Phonon using Wannier）是一个开源软件，用于 ab initio 计算电子–声子相互作用及相关材料性质。代码结合密度泛函微扰理论（DFPT）与最大局域化 Wannier 函数（MLWF），高效计算电子–声子耦合矩阵元，并实现温度依赖性质和声子辅助量子过程的预测。本文系统报告了 2016 年以来的重大功能扩展：输运模块（Boltzmann 方程）、超导模块（各向异性多带 Eliashberg 理论）、光学模块（声子辅助间接跃迁）、极化子模块（无需超胞）、以及能带重整化模块（特殊位移法）。

### 5. 最重要的部分

最关键的是"Wannier 插值 + DFPT"的组合使得电子–声子耦合矩阵元可在密集 k/q 网格上高效计算——这是所有五大模块的共同基础。没有 Wannier 插值，直接 DFPT 在密集网格上的计算量不可承受；有了它，才能在统一框架内覆盖从输运到超导到极化子的多种物理量。这一技术基石决定了 EPW 的实用价值。

### 6. 它是怎么做的

- **核心方法**：DFPT 计算粗网格上的声子性质与电子–声子矩阵元；MLWF 插值到密集 k/q 网格，实现收敛计算。
- **输运模块**：基于半经典 Boltzmann 输运方程，计算电场与磁场下的载流子迁移率和塞贝克系数。
- **超导模块**：各向异性多带 Eliashberg 理论，计算声子介导超导体的 Tc 与能隙。
- **光学模块**：声子辅助间接跃迁吸收/发射光谱计算。
- **极化子模块**：无需超胞即可计算小/大极化子性质。
- **能带重整化**：基于特殊位移法（special displacement method）计算温度依赖带隙与光学谱。
- **验证**：每个模块配示例计算（如 Si、GaAs、MgB₂ 等），与实验或高精度计算对比。
- **基线**：实验值、直接 DFPT 计算（有限网格）及文献结果。
- **未披露**：各模块的具体计算效率对比基准（如 Wannier 插值 vs 直接 DFPT 的加速比）未在摘要中给出。

### 7. 与别人不同在哪里

已有电子–声子计算工具多针对单一物理量（如 EPW 早期版本仅做电声耦合矩阵元、或 Elk/WIEN2k 的有限功能模块）。EPW 的独特性在于在统一框架内覆盖五大类物理量，且全部基于 Wannier 插值实现高效计算。与需超胞的传统极化子或超导计算相比，EPW 的方法大幅降低了计算成本。

### 8. 关键结果与证据

- 实现了**输运、超导、光学、极化子、能带重整化**五大模块的统一计算框架。
- 各模块提供示例计算并通过与实验/文献对比验证（如 MgB₂ 超导 Tc、Si 带隙温度依赖等）。
- 代码已被社区广泛使用，截至报告日被引用 **239 次**（CrossRef），成为电子–声子物理计算的事实标准工具之一。
- 支持块体与低维材料的电子–声子计算。

### 9. 局限与可迁移价值

局限包括：Wannier 插值对初始投影质量敏感（需经验选择投影轨道）；部分模块（如全各向异性 Eliashberg）计算成本仍较高；对强关联体系（如 Mott 绝缘体）的适用性有限。可迁移价值很高：EPW 可直接用于固态电解质中的离子–声子耦合分析、半导体载流子迁移率计算、超导材料筛选以及热电材料优化。

### 10. 我的判断

**跟进优先级：高。** 作为电子–声子物理领域的事实标准开源工具，其功能覆盖面和社区影响力使其成为计算材料与计算物理研究者必备的基础设施。

- **发布日期 / 类型 / 期刊**：2025-01-15；同行评审研究论文；Nature Machine Intelligence 7, 56–67 (2025)
- **DOI / 原文**：[10.1038/s42256-024-00956-x](https://doi.org/10.1038/s42256-024-00956-x)
- **代码 / 数据**：MACE 模型代码开源于 [ACEsuit/mace](https://github.com/ACEsuit/mace)（GitHub，1300+ stars）；本文的消融实验配置随代码发布。

### 2. 入选理由与期刊质量

机器学习原子间势（MLIP）在 2022–2024 年涌现了大量新架构（NequIP、MACE、Equiformer 等），但不同模型之间的关系和设计选择的影响缺乏系统分析。本文构建统一数学框架，将这些看似不同的模型纳入同一设计空间并进行系统消融，为社区提供了"什么设计选择真正重要"的定量答案。Nature Machine Intelligence 是机器学习领域的顶级期刊，适合这种兼具理论深度与实用指导意义的工作。

### 3. 一句话亮点

构建统一数学框架将原子簇展开（ACE）与 NequIP 消息传递网络纳入同一设计空间，通过系统消融证明等变阶数、体阶数与特征通道数是决定精度–效率权衡的关键旋钮。

### 4. 核心工作

作者将原子簇展开（ACE）扩展为多层架构的一层，同时将 NequIP 的线性化版本理解为更大多项式模型的稀疏化。这一统一框架不仅揭示了看似不同架构之间的数学联系，还提供了系统探测设计选择（等变阶数、体阶数、消息传递层数、通道宽度等）对精度与效率影响的实用工具。通过在多个数据集上的消融实验，量化了各设计旋钮对域内/域外精度和平滑外推的贡献。

### 5. 最重要的部分

最关键的是"统一框架 + 系统消融"的结合：统一框架使不同模型可在同一坐标下比较，而消融实验则把"哪个设计选择真正影响精度"从直觉变成定量结论。没有统一框架，消融无法跨架构进行；没有消融，框架只是数学美观。二者结合使其成为 MLIP 架构设计的指导性参考。

### 6. 它是怎么做的

- **数学框架**：将 ACE 推广为多层架构，定义等变特征的多项式基；将 NequIP 线性化版本映射为该基的稀疏子集，建立等价关系。
- **消融实验**：在统一框架内系统变化等变阶数（L=0–3）、体阶数（ν=1–4）、消息传递层数（1–4 层）和通道数。
- **数据集**：多个分子与材料数据集（包含 rMD17、3BPA、水液体等），评估域内精度、域外外推与构象能面平滑性。
- **评价指标**：能量与力的均方根误差（RMSE）、训练效率、推理速度。
- **基线**：NequIP、Allegro、原始 MACE 及 ACE 的不同配置。
- **未披露**：部分大规模训练的计算资源消耗明细。

### 7. 与别人不同在哪里

已有的 MLIP 架构论文（NequIP、MACE、EquiformerV2 等）各自提出新模型并通过基准测试展示优势，但缺乏跨架构的统一分析和系统消融。本文不是提出又一个新架构，而是回答"为什么这些架构有效"和"哪些设计选择是关键"——这是从经验式模型开发走向理论指导设计的重要一步。

### 8. 关键结果与证据

- 统一框架成功将 **ACE 与 NequIP** 纳入同一数学表示。
- 消融实验定量证明**等变阶数（L）和体阶数（ν）是精度提升的主要驱动**，而过度增加层数收益递减。
- 在域外外推任务中，高体阶数模型表现出更好的平滑性与泛化能力。
- 该框架直接指导了 MACE 系列模型的设计优化。

### 9. 局限与可迁移价值

局限包括：消融实验覆盖的架构范围有限（未涵盖 Allegro、EquiformerV2 的全部变体）；长程相互作用的处理未在框架中统一讨论；实验主要在分子体系上验证，对周期性材料的系统消融较少。可迁移价值很高：框架可直接指导材料科学领域的 MLIP 架构选择——对于固态电解质 AIMD 模拟，可根据精度需求与计算预算选择最优的等变阶数与体阶数组合。

### 10. 我的判断

**跟进优先级：高。** 这是 MLIP 领域少有的理论统一+系统消融工作，为后续架构设计提供了定量指导，对所有使用或开发等变 ML 势的研究者都有参考价值。

## 5. MACE-OFF：有机分子短程可迁移机器学习力场

### 1. 基本信息

- **英文标题**：MACE-OFF: Short-Range Transferable Machine Learning Force Fields for Organic Molecules
- **作者**：Dávid Péter Kovács、J. Harry Moore、Nicholas J. Browning、Ilyes Batatia、Joshua T. Horton、Yixuan Pu、Venkat Kapil、William C. Witt
- **主要机构**：剑桥大学、博世研究中心
- **发布日期 / 类型 / 期刊**：2025-05-19；同行评审研究论文；Journal of the American Chemical Society 147(23), 17598–17611 (2025)
- **DOI / 原文**：[10.1021/jacs.4c07099](https://doi.org/10.1021/jacs.4c07099)
- **代码 / 模型 / 数据**：预训练 MACE-OFF 模型与代码开源于 [ACEsuit/mace-off](https://github.com/ACEsuit/mace-off)（GitHub）；模型提供 3 种规模（s、m、l），可直接下载使用。

### 2. 入选理由与期刊质量

经典分子力场（如 AMBER、OPLS、GAFF）在生物分子与药物模拟中使用了 50 年，但精度和可迁移性长期不足。MACE-OFF 用现代等变消息传递架构（MACE）仅凭短程模型即可达到接近 DFT 的精度，并覆盖整个有机化学元素空间（H、C、N、O、F、P、S、Cl、Br、I）。JACS 作为化学顶级综合期刊，适合这种挑战经典范式且验证充分的工作。

### 3. 一句话亮点

仅使用短程 MACE 架构训练的可迁移机器学习力场，在二面角能面、分子晶体、液体性质与自由能面等广泛任务上达到接近第一性原理的精度，证明"长程静电/色散项可被短程模型隐式捕获"。

### 4. 核心工作

作者基于 MACE（高阶等变消息传递神经网络）架构，训练了一系列覆盖 10 种有机化学元素（H/C/N/O/F/P/S/Cl/Br/I）的短程可迁移力场 MACE-OFF。训练数据来自高精度量子化学计算（ωB97M-D3/cc-pVTZ 级别或更高）。力场在未见过分子的二面角扫描、分子晶体晶格能、液体密度与径向分布函数、含量子核效应的振动谱以及自由能面计算等任务上进行系统验证。

### 5. 最重要的部分

最关键的是"短程模型足够好"这一结论的验证力度：经典力场依赖显式长程静电与色散项，而 MACE-OFF 仅用短程截止就实现了跨域精度。作者不是在一个任务上展示，而是在气相、凝聚态（晶体+液体）、量子核效应与自由能面四类截然不同的任务上系统验证。如果短程模型只能在某一类任务上有效，结论将大幅缩水；四类任务全覆盖使其成为可信的通用力场替代方案。

### 6. 它是怎么做的

- **架构**：基于 MACE 高阶等变消息传递网络，等变阶数 L=2 或 3，提供 small/medium/large 三种规模（参数量 ~100K–2M）。
- **训练数据**：包含 SPICE 数据集（药物类分子）、COMP6 系列（有机分子晶体、液体等）等，参考计算使用高精度 DFT（ωB97M-D3）。
- **截止半径**：6 Å（短程）。
- **验证任务**：未见分子二面角扭转能面（与 DFT 对比）、分子晶体晶格能与结构（vs 实验晶体结构库）、液体性质（密度、RDF vs AIMD）、量子核效应（路径积分分子动力学振动谱）、自由能面（构象采样）。
- **基线**：经典力场（GAFF、MMFF94 等）、其他 ML 力场（ANI-2x 等）、直接 DFT 计算。
- **评价指标**：能量/力 RMSE、晶体结构 RMSD、液体密度偏差、振动谱峰值偏差。

### 7. 与别人不同在哪里

经典力场（AMBER、GAFF）依赖人工参数化的键合/非键合项和显式长程项；其他 ML 力场（ANI-2x）虽用神经网络但架构较旧。MACE-OFF 的差异在于：使用当前最强的等变消息传递架构（MACE），且证明仅靠短程模型即可覆盖气相到凝聚态的广泛性质——这挑战了"通用力场必须包含长程项"的传统认知。

### 8. 关键结果与证据

- 在未见分子的二面角能面上，**MACE-OFF 与参考 DFT 的偏差比经典力场低约一个数量级**。
- 对分子晶体，晶格能预测误差接近 DFT 本身的不确定度。
- 液体密度与 RDF 与 AIMD 模拟高度一致。
- 路径积分分子动力学（PIMD）验证了量子核效应预测能力。
- 自由能面计算给出与参考方法一致的构象布居。
- 截至 2025 年 5 月发表时已被引用约 **193 次**（CrossRef）。

### 9. 局限与可迁移价值

局限包括：短程截止在含显著长程电荷转移或离子相互作用的体系中可能不足；模型规模较大时训练成本高；金属/无机体系不在覆盖范围内；对反应性化学键的描述需进一步验证。可迁移价值很高：MACE-OFF 架构与训练范式可直接迁移至材料科学——有机/聚合物固态电解质（如 PEO 基体系）、有机-无机杂化钙钛矿、含能材料等的分子动力学模拟均可受益。

### 10. 我的判断

**跟进优先级：中–高。** 短程模型的跨域精度验证令人信服，对有机/聚合物材料模拟有直接实用价值；但其对固态无机材料的适用性尚未验证，跟进时应关注扩展到无机体系的进展。
