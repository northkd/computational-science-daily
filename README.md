# Computational Science Daily

每天北京时间 12:00 自动发布一份中文论文深度日报，共固定 5 篇论文。

## 每日选题

- **计算科学与固态电解质 3 篇**：计算化学、计算物理、计算材料的新技术/模型，以及新型固态电解质研究。
- **材料机器学习 2 篇**：可用于材料科学的 deep learning、LLM、foundation model、GNN、generative model、机器学习势、active learning 等工作。

## 解读重点

每篇论文均包括：

- 一句话亮点与核心贡献
- 整项工作中最重要的部分
- 数据、模型、算法、训练/求解与验证方法
- 与最接近工作或基线的实质差异
- 关键结果和证据
- 局限、对材料研究的可迁移价值与跟进优先级

## 报告位置

每天只创建或更新一份文件：[`reports/YYYY-MM-DD.md`](reports/)。

优先选择最近 7 天论文；不足时扩大到 30 天。固态电解质方向必要时扩大到 90 天，并明确标注论文日期。所有条目应链接论文原文及可用的官方代码、模型或数据。

> 内容用于科研信息跟踪，不替代对原始论文、代码、数据和实验条件的核验。
