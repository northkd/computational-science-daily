# Computational Science Daily

每天北京时间 12:00 自动发布一份中文论文深度日报，共固定 5 篇论文。

## 每日选题

- **计算科学与固态电解质 3 篇**：计算化学、计算物理、计算材料的新技术/模型，以及新型固态电解质研究；其中至少 1 篇为固态电解质方向。
- **材料机器学习 2 篇**：可用于材料科学的 deep learning、LLM、foundation model、GNN、generative model、机器学习势、active learning 等工作。

## 时间与质量标准

- 候选范围为运行日前 **5 年内**，优先近 **3 年**，不强求当天或当周发表。
- 同行评审论文优先；机器学习方向也纳入 NeurIPS、ICML、ICLR 等高水平会议论文。
- 综合评估相关性、创新性、证据质量、基线比较、可复现性和期刊/会议声誉，不只看影响因子。
- 检查既往日报并按 DOI、标题和预印本编号去重。

## 解读重点

每篇论文均包括：

- 入选理由、期刊或会议在领域内的定位
- 一句话亮点与核心贡献
- 整项工作中最重要的部分
- 数据、模型、算法、训练/求解与验证方法
- 与最接近工作或基线的实质差异
- 关键结果和证据
- 局限、对材料研究的可迁移价值与跟进优先级

## 报告位置

每天只创建或更新一份文件：[`reports/YYYY-MM-DD.md`](reports/)。

所有条目应链接论文原文及可用的官方代码、模型或数据。

> 内容用于科研信息跟踪，不替代对原始论文、代码、数据和实验条件的核验。
